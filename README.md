## 🚀 使用方式

```bash
git clone https://github.com/UrJohnnyPi/Mathematics-I.git
```

- **DOCX 文件**：可使用 Word、WPS 或 Typora 等支持 DOCX 的编辑器打开；
- **PDF 文件**：任意 PDF 阅读器均可查看，推荐使用支持批注与手写的阅读器，方便做笔记；
- 按科目进入对应文件夹即可快速定位，文件名已包含章节与主题信息。
